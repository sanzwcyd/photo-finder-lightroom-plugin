# Photo Finder & Auto Filter

Lightroom Classic plugin that matches a client's file-name list against your catalog and auto-tags the results with Color Labels & Star Ratings.

## 🇬🇧 English

Stop hunting for files one by one — paste a client's shot list and let Photo Finder tag the matches in Lightroom Classic instantly.

### ✨ Features

- 🔍 Match many file names at once (paste from anywhere — automatically sorted one name per line)
- 🏷️ Auto-tag matches with Color Label and/or Star Rating
- 🎯 Search the entire catalog, or only the currently displayed photos
- 🌐 UI available in 14 languages (Indonesian, English, Malay, Thai, Vietnamese, Filipino, Simplified Chinese, Traditional Chinese, Spanish, Japanese, Arabic, Portuguese, Korean, French)
- 📋 Result summary + guidance on where to find the tagged photos via the Library Filter

### 📦 Installation

1. Download this repo (green **Code > Download ZIP** button, or check the **Releases** page for a direct download).
2. Extract it — make sure you have a folder named `PhotoFinder.lrplugin` (the folder name must keep the `.lrplugin` ending).
3. Open Lightroom Classic → **File > Plug-in Manager**.
4. Click **Add**, then select the `PhotoFinder.lrplugin` folder.
5. Make sure the status shows **"Installed and running"**.

### 🚀 Usage

1. Open **Library > Plug-in Extras > Photo Finder - Cari & Tandai Foto**.
2. Paste the client's file-name list into the text box.
3. Choose the search source, and the Color Label and/or Star Rating you want to use.
4. Click **Search** — matching photos are tagged and selected automatically.

Full instructions are in [`PhotoFinder.lrplugin/README.txt`](PhotoFinder.lrplugin/README.txt).

### 🖥️ Compatibility

Lightroom Classic (Windows). Built with the Lightroom SDK (Lua).

## 🇮🇩 Bahasa Indonesia

Nggak perlu cari file satu-satu lagi — tempel daftar pilihan klien, Photo Finder langsung menandai fotonya di Lightroom Classic.

### ✨ Fitur

- 🔍 Cocokkan banyak nama file sekaligus (paste dari mana saja — otomatis rapi jadi satu nama per baris)
- 🏷️ Tandai otomatis dengan Color Label dan/atau Star Rating
- 🎯 Cari di seluruh katalog, atau hanya di foto yang sedang ditampilkan
- 🌐 UI tersedia dalam 14 bahasa (Indonesia, English, Melayu, ไทย, Tiếng Việt, Filipino, 简体中文, 繁體中文, Español, 日本語, العربية, Português, 한국어, Français)
- 📋 Ringkasan hasil + panduan cara melihat foto yang sudah ditandai lewat Library Filter

### 📦 Instalasi

1. Download repo ini (tombol hijau **Code > Download ZIP**, atau lihat halaman **Releases** untuk unduhan langsung).
2. Ekstrak, pastikan kamu punya folder bernama `PhotoFinder.lrplugin` (nama foldernya harus tetap diakhiri `.lrplugin`).
3. Buka Lightroom Classic → **File > Plug-in Manager**.
4. Klik **Add**, pilih folder `PhotoFinder.lrplugin` tadi.
5. Pastikan status menjadi **"Installed and running"**.

### 🚀 Cara pakai

1. Buka **Library > Plug-in Extras > Photo Finder - Cari & Tandai Foto**.
2. Tempel daftar nama file dari klien ke kotak teks.
3. Pilih sumber pencarian, Color Label dan/atau Star Rating yang mau dipakai.
4. Klik **Cari** — foto yang cocok otomatis ditandai & dipilih.

Panduan lebih lengkap ada di [`PhotoFinder.lrplugin/README.txt`](PhotoFinder.lrplugin/README.txt).
